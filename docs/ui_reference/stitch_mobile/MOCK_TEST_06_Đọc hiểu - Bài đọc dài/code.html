BÀI ĐỌC: 日本の生活とゴミの出し方
420 ký tự

日本に住み始めたばかりの留学生にとって、一番困ることはゴミの捨て方かもしれません。町によってゴミを捨てる日や時間が細かく決まっています。

例えば、私の住んでいる町では、燃えるゴミは火曜日と金曜日の朝八時までに出さなければなりません。また、ペットボトルやビンなどのリサイクルできるゴミは水曜日です。

もしルールを守らないと、ゴミを集める人に持って行ってもらえないことがあります。ですから、住んでいる町役場でもらったゴミ出しのカレンダーを部屋の壁に貼って、毎日確認するようにしています。

最初は大変だと思いましたが、慣れると環境を守るためにとても大切なことだと分かるようになりました。
